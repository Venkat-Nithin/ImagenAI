# Imagen 2.0 – AI Image Generator

A full-stack AI image generation app that uses Stable Diffusion via Hugging Face or Replicate to create stunning visuals based on user prompts. Built with **React.js**, **Node.js**, **Express**, and **MongoDB**.

---

##  Features

-  Generate images from text prompts using Stable Diffusion
-  "Surprise Me" prompts for creative inspiration
-  Share your creations with the community
-  Search posts by prompt or creator name
-  Secure backend API with image hosting via Cloudinary
-  Secrets protected via `.env` (not pushed to GitHub)
